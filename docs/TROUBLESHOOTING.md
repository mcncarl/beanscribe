# 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 工作台找不到应用 | 是否在正确组织；版本是否已发布而非仅保存；可用范围是否包括自己 |
| 导航栏仍是旧名 | 从工作台重新固定同一应用，再去「更多 → 编辑」拖到下方并完成 |
| 页面要求测试口令 | 正式进程是否带了 `--identity-config`；应使用 `tools/run.py` 启动 |
| 提示仅本人可用 | `ownerOpenId` 是否来自当前 App ID，而非其他应用、union_id 或组织 user_id |
| JSAPI 鉴权失败 | App ID、Secret、可信域名、实际 HTTPS 页面 origin 和 `/minutes` 前缀是否一致 |
| 404 或资源空白 | 反向代理是否保留 `/minutes`；请使用教程的 `handle`，不剥掉前缀 |
| 502 | systemd 是否 active；Python 依赖、secret 文件 0600 和服务用户读权限是否正确 |
| WebSocket 连不上 | 代理是否支持 Upgrade、是否走同一 HTTPS/WSS 站点、有无第三方登录拦截 |
| 找不到 libopus | Linux 安装 `libopus0`，macOS 安装 `opus`；必要时用 `SOUNDCORE_OPUS_LIBRARY` 指向自己的动态库 |
| 能扫描但握手失败 | 型号/固件、蓝牙占用、平台授权、设备认证能力；不要直接重置或解绑 |
| 网页停止了，设备还在录 | 按设备实体键停止；网页停止的是接收，无法代替硬件按键 |
| 开头几秒缺失 | 已知实时发现/握手延迟；录后识别不能恢复没送到服务器的音频 |
| 录后识别超限 | 当前 StepFun 路径按 WAV 大小约 99 MB 限制，16 kHz 单声道约 51 分钟；实时录音上限不是录后识别上限 |
| 豆包选项不出现 | `volcAppId`、token 文件是否同时配置；语音应用是否开通对应资源 |
| 总结/翻译失败 | StepFun Key、文本模型能力、网络和服务商额度；豆包语音 token 不代替文本服务 |
| 文档创建失败 | 四项文档权限是否发布；组织 user_id、文档域名是否正确；组织策略是否允许 |
| 文档未自动生成 | 是否开启文档配置、录后任务是否完成、有没有识别出文字；无文字时保留音频但不创建空纪要 |
| 文档只写了一部分 | 任务会回读和恢复；遇到远端编辑冲突或创建结果不确定会停止，先看页面状态再决定重试 |
| 锁屏后中断 | 先测前台短录音，再逐步检查后台；系统后台限制无法靠网页保证永远绕过 |

## 应用发布和源码公开不同

飞书里「发布版本」是让指定组织成员能使用应用。GitHub 仓库公开是分享源码。公开源码不应开放你的录音库、密钥或飞书应用给所有人。

## 这是不是关闭原厂转写、替换原妙记？

不是。当前代码建立自己的转写链路和飞书文档，不修改官方妙记的实时字幕数据源。原厂应用仍可能同步并处理设备录音。仓库没有经过验证的“只关闭原厂 ASR、保留原厂绑定与升级”的设置教程，也不要求通过解绑来实现当前功能。

## 报告问题时提供什么

提供手机系统、飞书版本、D3200 固件版本、仓库 commit、操作步骤、经过遮挡的错误代码和是否使用实时/录后识别。避免上传 App Secret、用户标识、服务地址、原始录音、完整日志或 HAR。先在本机核对内容再分享。
