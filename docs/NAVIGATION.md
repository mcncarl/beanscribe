# 把「录音豆」放到飞书最下面的导航栏

先完成 [应用部署和内部发布](SETUP.md)。这里固定的是工作台中的自建「录音豆」应用，点开后进入同一个 H5 录音库。

## 先找到正确入口

1. 在 iPhone 打开飞书，切换到发布应用的组织。
2. 在消息页底部点「更多」。如果底部已有「工作台」，也可以直接点工作台。
3. 进入「工作台」，搜索「录音豆」。若只是在工作台的常用区没看到，通过添加应用/全部应用查找。
4. 点开一次，确认是你部署的录音页面，再返回工作台。

如果完全找不到，先检查应用版本是否**已发布**、你是否在**可用范围**内、手机是否处于正确组织。改变导航位置不能解决这些问题。

## 添加并移到下方

1. 在**工作台的应用图标**上长按「录音豆」。
2. 在出现的菜单里点「添加到导航栏」。这一步可能先把它加入「更多」列表。
3. 返回消息页，点底部的「更多」。
4. 在展开的应用区域点右侧「编辑」。
5. 如果下方固定位置已经满了，长按一个可移动的入口（例如「工作台」），把它拖回上方「更多」区域。它仍可从更多打开。
6. 在上方找到「录音豆」，长按后拖到下方固定导航栏。要放到第四项，可拖到「日历」与「云文档」之间；其他入口名称和数量以你组织的配置为准。
7. 点「完成」保存。
8. 返回消息页，确认「录音豆」现在能直接看到。点一次，应直接进入录音列表。
9. 再返回消息页、再次打开，确认位置和名称都保留，且不需要额外输入维护口令。

你可以得到类似这样的排列：

```text
消息  |  其他应用  |  日历  |  录音豆  |  云文档  |  更多
                              ↑
                       点击打开自己的录音库
```

以上拖动路径来自本项目 iPhone 飞书的既有实测，当前教程重新核对了本地验收记录。具体按钮可能随飞书版本和组织策略变化；本次源码发行没有重新操作你的手机。

## 两个容易走错的地方

**从网页右上角「…」创建快捷方式**：这可能固定网页链接，保留旧标题或生成重复入口。要复现这里的应用入口，回到工作台长按真正的应用图标操作。

**改名后底部仍显示旧名称**：先确认新名称已经随版本发布；然后在「更多 → 编辑」把旧固定入口移回上方，再从工作台重新添加同一应用、拖回下方，点完成。仅刷新网页不一定更新飞书缓存的导航标题。

## 没有「添加到导航栏」或无法拖动

先确认当前不是网页正文上的长按菜单。若组织策略限制导航，请管理员配置：

1. 飞书管理后台 →「企业设置」→「企业文化」→「功能配置」→「客户端导航栏配置」。
2. 选「移动端」→「编辑导航」。
3. 在外露应用区添加 →「在已安装的应用中选择」→选已发布的「录音豆」。
4. 调整位置，保存；确保应用可见范围包括你。

飞书官方说明：此管理入口需要超级管理员或企业文化管理权限；成员调整过的导航可能与默认配置不同，固定的首项也可能不允许成员移动。[管理员配置客户端导航栏](https://www.feishu.cn/hc/zh-CN/articles/360049067840)

管理员无需把应用开放给全部成员。此仓库默认只有一个录音库，应保持单人可用范围。
