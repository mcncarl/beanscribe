# 发行版验证范围

整理日期：2026-11-04。

## 本次通用化做了什么

- 保留当前 H5 产品的前端、蓝牙协议、网关、两家 ASR 适配器、录后任务、自动文档与回归测试。
- 把写死的飞书 App ID 改为部署配置；删除对作者本机秘密管理器的隐式依赖。
- 配置模板全部使用占位值；增加本地配置校验，正式启动时拒绝未配置 App ID。
- 用合成正弦波替代测试依赖的真人录音，使测试无需私有素材。
- 用自行绘制的空态资源替代不适合分发的安装包素材。
- 编写从创建应用、部署到固定导航、录音和回读的步骤，并提供 GitHub CI。

## 本地检查

在独立发行目录运行：前端 229 项测试通过，后端 149 项测试通过。测试包括网关认证、身份匹配、数据持久化、重启恢复、音频处理、文档任务、蓝牙状态机以及通用配置。

已生成完整浏览器蓝牙 bundle。97 个发行文件的检查通过，覆盖可分发文件、文档链接、资源引用、供应商文件哈希和常见隐私模式。浏览器打开独立发行目录的当前设备页、空录音列表正常；没有进行真机连接或语音调用。

测试采用合成音频和本地模拟服务，没有使用作者真实账号调用付费 ASR 或创建飞书文档。当前回归数量反映本次基线，后续提交以 CI 实际结果为准。

首次 Linux CI 暴露了模拟蓝牙测试的等待问题：固定的事件循环次数不保证后台加密任务已经完成。测试夹具现改为等待实际加密 Promise，并在断言失败后释放会话定时器；产品录音逻辑不因此改变。相关 56 项本地测试复核通过，云端最终结果请看仓库 Actions 中对应提交。

## 与真机使用分开看

原实现已有 iPhone + D3200 的连接、实录、字幕、保存重开、导出及飞书底部导航验收记录；私人截图和录音没有进入仓库。通用发行版未在另一位用户的飞书租户或设备上重新完成全流程。

此次未改变作者现有服务器部署，也未刷写固件、操作手机或关闭原厂 ASR。systemd/Caddy 模板需要在使用者自己的 Linux 服务器按教程检查；本次本地环境是 macOS，不将模板静态核对称为全新公网部署验收。

复现效果仍需自己的应用权限、域名、提供商能力和兼容设备。完成 [真机验收表](USAGE.md)后，才能称为你自己的部署已通过。原生小程序实验壳、固件改造、原妙记接管均不属于已验收交付。
